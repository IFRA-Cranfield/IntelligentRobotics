# Intelligent Robotics
## Simple ROS 2 Package
The ros2ir_simplepackage consists of a raw ROS 2 Package containing 2 short Python and C++ scripts which print a "Hello World!" message. This package enables the understanding of how Python and C++ scripts are defined, compiled and executed within a ROS 2 Environment.

Both scripts are executed by running the following commands in the terminal shell:
```sh
# Python script:
ros2 run ros2ir_simplepackage HelloWorld.py
# C++ script:
ros2 run ros2ir_simplepackage helloworld
```
